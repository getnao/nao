## Summary

* production and local dev were installing dependencies in two different ways, which sometimes pulled slightly different package versions and caused bugs that only showed up in production (e.g. the recent input schema issue of zod/streamdown)
* switched the Docker build from `bun` install back to `npm ci`, so everything installs from a single source of truth (= package-lock.json)
* bumped Node to 24.18.0 in `.nvmrc` (matching the Docker prod image), which ships npm 11.16.0 natively — so dev, CI and prod now run the same Node and npm with no manual upgrade needed  
restored the engines guardrail (node >=24.18.0, npm >=11.11.0), now that Node and npm versions are consistent everywhere
* bumped `boxlite` (0.3.0 → 0.9.7) : the old version listed platform binaries that were never published, which broke npm ci — the new version fixes that and also adds Linux/ARM support
